DEVELOPER'S MESSAGE

Why I Built EducationHub

Hello! I'm Bishesh Ghimire, a B.Sc. CSIT student and aspiring web developer.

I created EducationHub as a learning platform where students can easily discover courses, explore subjects, connect with teachers and continue their learning journey in one place.

While developing this project, my goal was not only to build a website, but also to understand how a complete real-world web application works.

From designing the frontend to developing the backend, connecting MySQL and building APIs, this project has helped me improve my development skills and learn how different technologies work together.

"I believe every project is an opportunity to learn something new, solve a problem and become a better developer."
